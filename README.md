# Don't Panic! - Дневник самонаблюдения

Telegram Mini App для пациентов с паническим расстройством, помогающий справляться с тревогой и паническими атаками через структурированное самонаблюдение.

## Описание

**DontPanic** - это приложение для ведения дневника самонаблюдения при панических атаках.

### Зачем вести дневник при паническом расстройстве?

1. **Переключение внимания** - детальное описание происходящего отвлекает от катастрофических мыслей и телесных ощущений
2. **Выявление паттернов** - со временем становятся видны триггеры и закономерности
3. **Когнитивная реструктуризация** - анализ записей помогает оспорить иррациональные убеждения
4. **Отслеживание прогресса** - можно увидеть, как меняется интенсивность и частота приступов
5. **Материал для терапии** - структурированные записи помогают психотерапевту лучше понять ситуацию

## Что фиксирует приложение

Каждая запись включает 7 разделов:

- **Дату и время** - когда началась тревога/паническая атака
- **Местоположение** - где вы находились (может быть триггером)
- **Окружение** - были ли вы одни или с кем-то
- **Обстоятельства** - физическое и эмоциональное состояние, предшествующие события
- **Триггер** - что конкретно запустило паническую атаку
- **Мысли** - катастрофические интерпретации ("у меня инфаркт", "я умру", "я схожу с ума")
- **Телесные ощущения** - детальное описание физических симптомов (сердцебиение, одышка, головокружение и т.д.)
- **Действия** - что вы делали, чтобы справиться (дыхательные упражнения, техники заземления, обращение за поддержкой)

### Почему важна детальность?

**Чем подробнее вы описываете свое состояние, тем эффективнее работает техника.** Подробное описание:
- Переключает фокус внимания с паники на процесс наблюдения
- Помогает "заземлиться" в настоящем моменте
- Превращает пугающий опыт в структурированные данные
- Снижает субъективную интенсивность переживаний

## Технологии

- **React** 19 с TypeScript
- **Tailwind CSS** 4 для стилизации
- **React Router** для навигации
- **Telegram Web App SDK** для интеграции с Telegram
- **Vite** для сборки
- **Telegram Cloud Storage** для хранения данных

## Структура данных

Каждая запись включает:
```typescript
{
  id: string;
  location: string;          // Местоположение
  witnesses: string;         // Окружение (один, с друзьями, в толпе)
  circumstances: string;     // Обстоятельства (физ/эмоц состояние)
  trigger: string;           // Триггер
  thoughts: string;          // Катастрофические мысли
  bodyFeelings: string;      // Телесные ощущения
  actions: string;           // Копинг-стратегии
  emoji: string;             // Автоматически подобранная эмоция
  title: string;             // Автоматически сгенерированный заголовок
  tags: string[];            // Автоматически извлеченные теги
  createdAt: string;         // Дата создания
  updatedAt: string;         // Дата последнего обновления
}
```

## Установка и запуск

### Предварительные требования

- Node.js 18+
- npm или yarn

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Деплой на GitHub Pages
npm run deploy
```

## Деплой

Приложение настроено для автоматического деплоя на GitHub Pages:

1. Соберите проект: `npm run build`
2. Задеплойте: `npm run deploy`

Приложение будет доступно по адресу: `https://[username].github.io/dontpanic/`

## Интеграция с Telegram

### Создание бота

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Установите Telegram Web App URL в настройках бота
3. Активируйте Cloud Storage для сохранения данных пользователей

### Настройка

В настройках бота укажите URL вашего приложения:
```
/setmenubutton
/newapp
```

## Функциональность

### Основные возможности

- ✅ Создание записей во время панической атаки или после нее
- ✅ Просмотр истории записей с группировкой по датам
- ✅ Редактирование существующих записей (можно дополнить рефлексией)
- ✅ Удаление записей
- ✅ Поиск по записям
- ✅ Автоматическое определение эмоций и тегов
- ✅ Экспорт всех записей для анализа с AI
- ✅ Поддержка темной темы
- ✅ Адаптивный дизайн

### Анализ с помощью AI

Приложение позволяет экспортировать все записи в формате, оптимизированном для анализа с помощью AI-ассистентов (ChatGPT, Claude и др.). AI помогает:

- Выявить триггеры и паттерны панических атак
- Определить связь между обстоятельствами, мыслями и телесными ощущениями
- Проанализировать катастрофические интерпретации
- Оценить эффективность копинг-стратегий
- Оценить динамику изменений
- Получить рекомендации по техникам когнитивной реструктуризации

## Для кого это приложение?

- **Пациенты с паническим расстройством** - как инструмент самопомощи между сеансами терапии
- **Люди с повышенной тревожностью** - для отслеживания эпизодов тревоги
- **Пациенты на когнитивно-поведенческой терапии (КПТ)** - дневник является частью КПТ-протоколов
- **Психотерапевты** - как вспомогательный инструмент для пациентов

## Важные замечания

⚠️ **Это приложение НЕ заменяет профессиональную психологическую помощь.** Оно является вспомогательным инструментом для работы с паническим расстройством под руководством квалифицированного специалиста.

⚠️ **При остром приступе** используйте экстренные техники (дыхательные упражнения, техники заземления), а дневник ведите после того, как острая фаза пройдет, или используйте сам процесс ведения дневника как технику переключения внимания.

⚠️ **Если панические атаки усиливаются или появляются суицидальные мысли** - немедленно обратитесь к врачу или психотерапевту.

## Безопасность и конфиденциальность

- Все данные хранятся в Telegram Cloud Storage пользователя
- Приложение не имеет собственного бэкенда
- Данные не передаются третьим лицам
- Доступ к записям имеет только владелец Telegram-аккаунта
- Записи хранятся в зашифрованном виде

## Научная основа

Приложение основано на принципах:
- **Когнитивно-поведенческой терапии (КПТ)** - золотой стандарт лечения панического расстройства
- **Техники переключения внимания** - доказанная эффективность при панических атаках
- **Структурированного самонаблюдения** - базовый инструмент КПТ
- **Техники заземления (grounding)** - помогают "вернуться" в настоящий момент
